# SPP 管理員登入流程

## 目的

確保管理員能以正確且安全的方式登入 One Identity Safeguard for Privileged Passwords（SPP）管理介面。

## 適用範圍

畫面與中文操作名稱於 2026-09-30 以 SPP 9.0.0.2807 Web 用戶端核對；文末 8.0 LTS 官方文件作為原理參考，不代表所有 9.0 行為均已驗證。

## 前置條件

- 已取得 SPP 管理員帳號及初始密碼
- 用戶端裝置可連線至 SPP 管理 IP
- 使用符合該版官方系統需求且仍受維護的瀏覽器，不將固定舊版號當成通用門檻。

## 操作步驟

### 登入後辨識操作區域

登入後先確認右上角使用者與提供者，再從首頁核對叢集節點、角色與完整版本。下圖的叢集卡片顯示 `9.0.0.2807`；圖片裁去登入身分與主機名稱列。

![SPP 登入後首頁與叢集版本](../../images/sop/spp-home.jpg)

圖 1：實際首頁。我的要求與核准是不同作業區；數字只是截圖當時的狀態。

左側「資產管理」處理目標主機、納管帳戶與密碼設定檔；「安全性原則管理」處理權利與存取流程；「裝置管理」處理備份、憑證與登入提供者。登入成功只代表平台驗證通過，不能據此認定目標密碼、備份或側錄均正常。

### 實施與驗收程序（尚未實跑）

1. 開啟瀏覽器，前往 `https://<CUSTOMER_SPP_FQDN>/`，確認名稱與憑證信任正常。
2. 選擇正確的登入提供者，輸入個人管理帳號與密碼；External Federation 依導向頁面完成登入。
3. 若環境啟用多因素驗證（MFA），依提示完成第二因素驗證。
4. 登入成功後，畫面將導向 SPP 儀表板（Dashboard）。
5. 確認右上角顯示正確的登入帳號名稱。

## 注意事項

- 鎖定次數與期間依 SPP 本機登入控制或外部身分提供者設定，不假定為固定 5 次。
- 請勿使用公用電腦或不受信任的網路環境登入。
- 工作階段逾時依實際設定，離開前儲存作業並登出。
